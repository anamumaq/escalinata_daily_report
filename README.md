# ☕ Daily Report Processor para la Escalinata Cafe

![Status](https://img.shields.io/badge/Status-Active-success)
![Python](https://img.shields.io/badge/Python-3.10+-blue)
![Excel](https://img.shields.io/badge/Data--Source-Excel%20%2F%20SENDA-green)

Este repositorio contiene la herramienta de automatización y procesamiento de datos para la **gestión diaria de la cafetería y espacio de coworking**. 
El sistema toma la exportación en bruto (*raw data*) de la plataforma **SENDA** y la transforma en información estructurada para el control de operaciones y la toma de decisiones.

---

## 📌 Objetivo del Proyecto

Optimizar el flujo de trabajo administrativo ara contrsatar las ventas en real vs en sisteme

## 🛠️ Stack Tecnológico

*   **Lenguaje:** Python 3.10+
*   **Librerías Clave:** `pandas`, `openpyxl`, `Plotly`, `Streamlit`
*   **Entorno:** Ubuntu Linux
